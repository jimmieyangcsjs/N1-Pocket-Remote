N1 需已启动并与手机连接到同一局域网。

电视画面

点击“刷新截图”查看当前画面

触控板

在下方移动电视上的指针，轻触点击，按住约 0.6 秒长按。

正在读取屏幕尺寸… 指针待命
滑动移动 · 轻触点击 · 按住长按

指针位置按 N1 的电视分辨率和手机触控面积自动换算；切换页面后会自动隐藏。

已安装应用

点击图标直接启动；系统应用只能启动，用户应用可由右上角按钮卸载。

发送文字到 N1

先在 N1 上点开搜索框或输入框，再在下方输入并发送。首次使用请切换到 N1 Remote 输入法。

安装到 N1

从手机选择一个 APK，文件会直接上传到 N1 并安装覆盖旧版本。
